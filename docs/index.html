Everything a Finder user expects

Nothing is unpacked until you ask. Opening a 100,000-file archive takes about half a second.

Browse like a folder

A sidebar of folders, a sortable list, and an inspector. Double-click to open, ⌘↑ to go back.

Preview in place

Select a file and see it, or press Space for Quick Look. Previews are temporary and deleted when you close the window.

Extract only what you need

Drag items to Finder, copy and paste them, or extract a selection. Files are written only when you drop them.

Search the whole archive

Match names, paths or extensions (*.pdf) as you type, even in huge archives.

Add and delete

Drop files onto the window to add them, or delete items. The archive is rewritten safely and checked before it replaces the original.

Names that make sense

Archives from Windows and older systems often have garbled names. QuickZip detects Shift-JIS, GBK and Cyrillic, and lets you choose.

Careful with archives you didn’t make

ZIP files can be crafted to cause harm. QuickZip treats every archive as untrusted.

Nothing escapes

Paths that climb out of the destination folder and links that point outside it are refused.

Bombs defused

Absurd sizes, impossible compression ratios and overlapping entries are detected before anything is decompressed.

Gatekeeper stays on

Extracted items keep the archive’s quarantine flag, so macOS still checks downloads the way it should.

Verify on demand

Check every file against its stored checksum without writing anything to disk.

No network. No third-party code.

The app is sandboxed with no network access, and built only on Apple’s frameworks. It can’t phone home because it can’t connect.

Fuzz-tested

The directory parser is fuzzed in continuous integration against thousands of deliberately damaged archives.

Fast on big archives

Measured on an Apple silicon Mac by the benchmark suite that runs on every change.
